二、穩定產出銀星/金星作物的技巧：

  1. 施用質量肥料 (Quality Fertilizer)：解鎖農業科技，播種前對田地施用「質量肥料 I」，能將無星或銅星種子在採收時機率升級為銀星作物。
  2. 升星循環：採收銀星作物時會噴出銀星種子，再施用肥料即可滾動出金星種子與金星作物。
  3. 農夫商店升級：在村莊南邊農夫處大量交易提升等級至 Tier 2，可直接購買帶星級的高品質種子。

三、交付步驟：

備妥作物放入背包，於暴食之日（週三）到死馬酒館南側與商人交談點擊任務交付即可。完成後解鎖商人家傳首飾贖回與貿易外銷流水線。

一、黑色顏料避坑須知：

在鍊金工作台放「灰燼 + 水」會產出生命的黏液（生命溶液），因為灰燼屬於生命系屬性，水會將其萃取為溶液。黑色顏料的正確合成組合只有：灰燼 + 油 或 石墨 + 水。

二、核心藥劑合成公式：

  • 黑色顏料：灰燼 + 油（或石墨 + 水）。墨水原料。
  • 提速藥水：加速粉末 + 混亂溶液 + 血液。大幅提升跑圖速度。
  • 酸液：毒性粉末 + 混亂溶液。占星家任務與開箱必備。
  • 鹼性注射液：鹼性試劑 (生命粉末 + 毒性溶液 + 水) + 血液 + 水。
  • 金色注射液：金色長生不老藥 (金粉 + 毒性溶液 + 混亂精華) + 血液 + 水。
