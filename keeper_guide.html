二、核心重要藥劑合成配方：

  • 黑色顏料：灰燼 + 水（或碳黑 + 油）。墨水原料。
  • 提速藥水：加速粉末 + 混亂溶液 + 血液。大幅提升跑圖速度。
  • 酸液：毒性粉末 + 混亂溶液。占星家任務與開箱必備。
  • 鹼性注射液：鹼性試劑 (生命粉末 + 毒性溶液 + 水) + 血液 + 水。
  • 銀色注射液：銀色長生不老藥 (銀粉 + 秩序溶液 + 生命精華) + 血液 + 水。
  • 金色注射液：金色長生不老藥 (金粉 + 毒性溶液 + 混亂精華) + 血液 + 水。

常見問答：胡蘿蔔種子只能用買的嗎？如何實現無限自給自足？ 農業經營與賺錢套路
▼

結論：不是只能用買的！只要掌握肥料機制，就能「越種越多」徹底告別花錢。

  1. 初始啟動：初次只能在村莊南邊向農夫 (Farmer) 購買一兩批（種下一壟田需 4 顆種子）。
  2. 白嫖種子的關鍵 —— 施用肥料：
    • 不施肥：採收時通常只掉落 3～4 顆種子，可能持平或虧本。
    • 施用泥炭 (Peat)：用作物廢料在堆肥箱發酵取得，施肥後種子回本率大幅提升。
    • 施用生長增強劑 / 質量肥料 (Quality Fertilizer)：採收時一壟田會噴出 4～6 顆種子，收穫量直接大於消耗量，種子源源不絕！
  3. 農業天賦加成：在農業科技樹點出「農業專精/農業天才」，全作物收穫量與種子掉落率全面上升。
  4. 後期殭屍農場：指派殭屍到田裡工作，會自動維持種子收放循環，自動把胡蘿蔔送入地窖供驢子吃。

常見問答：水（水滴 / 水桶）哪裡可以取得？如何分解？ 必備問答速查

一、取得與分解操作（無限免費資源）：

  1. 找到水井 (Well)：自家院子西南側（菜園正上方）就有一口現成的水井。
  2. 打水：靠近水井按下互動鍵打水，每次打水消耗微量體力，獲得 乾淨的水桶 (Bucket of clean water)。
  3. 倒出水滴（重要）：打開背包選中「水桶」，點擊「使用 (Use)」，角色會將水倒出：
    • 獲得：水滴 (Water) × 20 + 空桶 (Empty bucket) × 1。

二、核心用途：

  • 二級熔爐燒瓶：消耗 水 × 1 + 河流沙子 × 2 燒成 3 個錐形燒瓶。
  • 鍊金調配：合成黑色顏料、鹼性試劑與各類注射液必備溶劑。
  • 烹飪：在廚房烤箱製作生麵團、麵包的原料。
